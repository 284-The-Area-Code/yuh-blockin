# YuhBlockin Vehicle Universe

Vehicles are the primary visual characters.

Vehicle personality can be communicated through:

- movement
- headlights
- indicators
- braking
- positioning
- acceleration
- subtle reactions

Vehicles should remain sophisticated and consistent — well-designed and
recognizable within the 2D flat/vector style, not photoreal (revised
2026-09-30 for the 2D direction).

When the same vehicle appears in multiple shots, maintain:

- body shape
- color
- wheels
- accessories
- proportions
- visual identity

Use reference images when supported.

Do not rely on generated license-plate text for important information.

Use real assets during compositing when readable text is required.
