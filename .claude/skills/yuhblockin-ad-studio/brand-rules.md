# YuhBlockin Brand Rules

The existing YuhBlockin project is the source of truth for:

- logo
- colors
- typography
- UI
- pricing
- features
- product claims
- platform availability

Never invent brand information.

Never redraw or modify the official logo.

Never invent UI.

Never invent pricing.

Never invent statistics.

Never invent product claims.

When exact UI or text is required, use the actual YuhBlockin assets during compositing.

If information cannot be verified, mark it UNKNOWN.
