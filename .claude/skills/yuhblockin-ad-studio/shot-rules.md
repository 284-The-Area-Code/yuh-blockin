# YuhBlockin Shot Rules

Each shot should define:

- shot ID
- duration
- purpose
- subject
- environment
- camera
- camera movement
- subject movement
- lighting
- audio
- continuity requirements
- reference assets
- model recommendation
- post-production requirements

Use one primary action per shot whenever possible.

Maintain:

- vehicle identity
- direction
- lighting
- environment
- camera logic
- visual style

Avoid:

- malformed vehicles
- distorted wheels
- impossible physics
- unwanted humans
- random logos
- unreadable generated text
- excessive camera shake
