# YuhBlockin Ad Studio

This skill controls YuhBlockin advertising production.

It handles:

- concepts
- storyboards
- shot planning
- generation prompts
- video model selection
- visual consistency
- brand protection
- quality control

Advertising files are stored under:

advertising/
├── concepts/
├── storyboards/
├── prompts/
├── generated/
├── selected/
├── final/
└── references/
